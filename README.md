# Research on LLM Applications for DeepTech Project Review — Part 1

This repository contains all materials related to my research on reproducible LLM-based review of DeepTech projects, focusing on a very narrow part of the review process: **information extraction from project descriptions**.

This task appears to be particularly well suited for transfer to LLMs. More details are provided in the introduction to the article.

## Repository Structure

- `/data` — all data except the original project descriptions, including raw and processed LLM outputs
- `/scripts_requests` — scripts for generating LLM outputs
- `/scripts_processing` — scripts for calculations and data processing
- `/prompts` — all prompts used in the research
